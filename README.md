# Workout log

A simple workout log that runs in the browser and works like an app on your phone. Log exercises, weight, reps and sets, and browse your history by day. Data is saved in your browser's local storage on that device.

## Run it

Open `index.html` in any browser. No build step or dependencies.

## Put it online with GitHub Pages

1. Create a new repository on GitHub (for example `workout-log`).
2. Upload `index.html`, `README.md` and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then save.
5. After a minute your site is live at `https://<your-username>.github.io/workout-log/`.

## Use it like an app

Open the site on your phone, then choose **Add to Home Screen** in the browser menu.

## Notes

- Entries are stored per browser and per device. Clearing browser data erases them.
- Fonts load from Google Fonts, with system fallbacks when offline.
